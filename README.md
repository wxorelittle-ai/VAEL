# VAEL — торговый терминал и лаборатория измерений

Браузерное приложение без сборки (React 18 + Babel Standalone, всё компилируется на лету).
Работает на **реальных данных Bybit**. Торговля — **бумажная**: реальных ордеров система не
размещает никогда.

Прод: **https://vael.pro**

---

## Главное, что нужно знать

VAEL умеет две вещи, и вторая важнее первой.

**Первая** — обычный терминал: график, поиск точки входа, демо-сделки с честной комиссией
и трейлинг-стопом, портфель, лаборатория стратегий, автономный агент.

**Вторая** — VAEL **измеряет саму себя и показывает неудобные ответы**. Все выводы ниже
получены её же инструментами на живых данных, и каждый можно перезапустить на странице
**⚗ Исследования**.

Итог всех измерений: **торгового преимущества не найдено ни в одном направлении.**
Это не поломка и не недоделка — это ответ, полученный честно.

## Что было измерено и что выяснилось

Проверено 10 направлений. Все дали ноль или минус.

| Направление | Метод | Результат |
|---|---|---|
| Стратегии лаборатории | walk-forward, 13 встроенных + генерация + эволюция | минус при любых настройках |
| Точки входа 15m / 1ч / 4ч | воспроизведение без заглядывания вперёд | 29–37% побед при нужных **36%** |
| Ширина трейлинга (5 вариантов) | свип | минус везде (−6% … −10.7%) |
| Пороги отбора | сравнение политик | лучший исход — **$0** (не торговать) |
| Консенсус стратегий | наложение всех правил, 479 сделок | точность **падает**: 35% → 15% |
| Позиционирование (funding / OI / long-short) | 199 дней, независимые окна | корреляция **−0.01** |
| Свип R:R | 583 сделки | win rate механический, деньги минус **везде** |
| Мультитаймфрейм (фильтр 4ч) | 703 сделки | вход **по** тренду — **худший** (22%) |
| Издержки на 15m | измерение в единицах R | **1.53× всего валового эджа** |
| Polymarket | 1568 рынков, интервал Уилсона | **все 11 корзин калиброваны** |

### Три вывода, которые стоят всего остального

**1. Win rate — не показатель качества.** Он механически задан целью: `p₀ = 1/(1+R)`.
Измерено: цель 0.25R → **79.1% побед и −$20 093**. Теория совпала с фактом до десятых.
Хочешь 80% побед — поставь цель ближе. Заработать это не поможет.
Значение имеет только **ожидание за вычетом издержек**.

**2. Подтверждение = опоздание.** Чем больше индикаторов согласны — тем хуже результат
(35% → 15%). Вход по старшему тренду — худший из всех (22%). Причина структурная: все
индикаторы запаздывают и считаются из одной цены. Их единодушие значит, что движение
уже произошло.

**3. Издержки решают.** На 15m комиссия + проскальзывание = **1.53× всего валового эджа**.
Сетап убыточен **арифметически**, ещё до вопроса о качестве сигнала. Чем уже стоп — тем
больше доля издержек в R.

### Три ложные находки, которые методика поймала

Это главная причина доверять цифрам выше.

- **Корреляция 0.743** (long/short → цена). Выглядела открытием. Оказалась артефактом
  перекрывающихся окон: из «176 наблюдений» независимых было 8. На 199 днях → **−0.01**.
- **«Мисприсинг у фаворитов».** Оказался ошибкой формулы: ожидание не вычитало издержки.
- **«Расхождение» у Polymarket** на выборке n=2. На n=30 растворилось.

Каждая выглядела как эдж. Каждая была нулём.

## Запуск

```bash
python -m http.server 8080     # или npx serve .
```
Открыть `http://localhost:8080`. При первом запуске система попросит создать счёт
(имя + стартовая сумма) — это локальный профиль, без пароля и авторизации.

**Важно:** `index.html` не кэш-бастится. После его правки — `Ctrl+Shift+R`.
Остальные `.jsx` подгружаются с `?v=Date.now()` и обновляются сами.

### Бэкенд

Zero-dependency Node (`server/vael-api.js`), systemd-сервис `vael-api`, nginx проксирует
`/api/` → `127.0.0.1:8787`.

| Эндпоинт | Назначение |
|---|---|
| `/api/health` | статус + наличие ключей |
| `/api/news` `/api/market` `/api/stocks` `/api/airdrop-tvl` | внешние данные (обходят CORS) |
| `/api/state` | облачное сохранение состояния по устройству |
| `/api/pm/collect` `/api/pm/calibration` | выборка и калибровка Polymarket |
| `/api/bybit/account` | реальный счёт (нужен `BYBIT_API_KEY`, сейчас не задан) |
| `/api/assistant` | LLM-прокси (нужен `ANTHROPIC_API_KEY`, сейчас не задан) |

### Деплой

**GitHub с сервера недоступен** — `git pull` там не работает. Только через scp:
```bash
tar -czf d.tar.gz файлы… && scp d.tar.gz root@СЕРВЕР:/var/www/vael/
ssh root@СЕРВЕР "cd /var/www/vael && tar xzf d.tar.gz && rm d.tar.gz"
# бэкенд дополнительно: systemctl restart vael-api
```

## Правила торгового движка

- **Комиссия 0.055%** за сторону (тейкер Bybit), платится дважды. P&L реализуется **чистым**.
- **Проскальзывание 0.02%** за сторону — в бэктестах.
- **Тейк-профит не закрывает позицию** — прибыль бежит; закрывают стоп, трейлинг или ликвидация.
- **Трейлинг-стоп** подтягивается за ценой и никогда не откатывается назад.
- **Лимитные заявки** ждут и исполняются **по касанию фитиля** свечи.
- **Ликвидация всегда за стопом** — плечо подбирается так, чтобы стоп срабатывал первым.
- **Агент отказывается торговать** без эджа, подтверждённого на невиданных данных
  (≥8 сделок, PF ≥1.2). При отсутствии — ждёт и говорит об этом.

## Методика измерений

Почему цифрам можно верить:

- **Без заглядывания в будущее** — на каждом баре виден только прошлый.
- **Walk-forward** — отбор на одних данных, оценка на других, невиданных.
- **Честные издержки** — комиссия и проскальзывание вычитаются везде.
- **Размер выборки указывается** — а «100% побед на 1 сделке» отсеивается как шум.
- **Поправка на множественные сравнения** — за сессию ~15 тестов, порог значимости
  ужесточён до p < 0.004.
- **Интервал Уилсона** для долей — корректен на краях, где обычный ломается.
- **Ложная находка сначала опровергается**, а не публикуется.

## Ограничения

- Реального счёта Bybit и LLM-ассистента нет — ключи (`BYBIT_API_KEY`, `ANTHROPIC_API_KEY`)
  на сервере не заданы. Рыночные данные при этом полностью реальны.
- История Polymarket доступна только за последние ~120 дней: CLOB не отдаёт старые рынки.
- Выборка Polymarket описывает **недавний** рынок и не говорит о прежних режимах.
- `crypto.jsx` — 2052 строки, вдвое больше разумного предела.
